# Security Policy

Found a security vulnerability in Voyager? You can report it to GitHub and our maintainers will fix it!

## Supported Versions

These versions are currently eligible for security vulnerabilities:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| <1.0.0  | :x:                |

## Reporting a Vulnerability

You can report a vulnerability via GitHub's security vulnerability reporting feature, there should be a green "New report" button in the corner.
Or just report a vulnerability by clicking [here](https://github.com/Infinite1024Void/voyager/security/advisories/new).
